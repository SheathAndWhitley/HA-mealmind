# BBC Good Food dinner recipes

Dinner recipe URLs for the MealMind scraper, grouped by category.
Import this file in the web UI (Add recipe → Import from file) or run:
`python backend/src/recipe_scraper.py --file recipe_lists/bbc_good_food_dinners.md`

> Recipes marked *(from repo)* came from the original scraper list. The rest were written
> from memory and are **not verified**: some may not exist (the scraper reports them as
> `HTTP 404`). Delete those lines after the first import.
